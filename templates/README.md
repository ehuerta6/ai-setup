# Templates

Reusable structures for development artifacts.

| Template | Purpose |
| --- | --- |
| `SPEC.md` | Define behavior, constraints, decisions, and acceptance criteria |
| `PLAN.md` | Describe the implementation strategy for an approved spec |
| `ISSUE.md` | Structure implementation issues derived from a spec |
| `PULL_REQUEST.md` | Describe a completed change and its verification |
| `HANDOFF.md` | Transfer unfinished work to another agent or session |

Templates provide structure, not project requirements.
