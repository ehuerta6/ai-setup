# Rules

Stable rules that apply across projects unless explicitly overridden by project-specific instructions.

| File | Governs |
| --- | --- |
| `context.md` | Sources of truth and instruction precedence |
| `engineering.md` | General implementation behavior |
| `github.md` | Git and GitHub conventions |
| `writing.md` | Technical writing |
| `security.md` | Secrets, credentials, authorization, and trust boundaries |
| `ui.md` | General UI, UX, accessibility, and state handling |
| `definition-of-done.md` | Requirements for considering work complete |

Rules define constraints. Procedural workflows belong in `skills/`.
