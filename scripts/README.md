# Scripts

Automation for maintaining this AI setup.

| Script | Purpose |
| --- | --- |
| `install` | Connect this repository to supported AI tools |
| `sync` | Synchronize canonical configuration |
| `doctor` | Detect missing files, broken links, or configuration drift |
| `update` | Update managed third-party resources |

Only automate workflows after the manual process has proven useful.

Prefer small, reversible, and idempotent scripts.
